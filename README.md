# 📊 Student Performance Prediction

An ML-based project that analyzes student habits and predicts **exam performance** using Exploratory Data Analysis, Regression, and Classification techniques.

## 🎯 Project Objective

The main objective is to understand how factors such as **study hours, attendance, sleep, social media usage, exercise, and mental health** relate to students' exam scores and to build machine learning models for prediction.

## 🔍 Exploratory Data Analysis

The dataset is analyzed to identify:

* 📌 Numerical and categorical variables
* 📊 Data distributions and relationships
* 🔗 Correlations between features and exam scores
* ❌ Missing values
* ⚠️ Potential outliers
* 🎓 Factors associated with student performance

## 🛠️ Technologies Used

* 🐍 Python
* 📓 Jupyter Notebook / Google Colab
* 🧮 Pandas & NumPy
* 📈 Matplotlib & Seaborn
* 🤖 Scikit-learn

## 🤖 Machine Learning

### 📈 Regression

**Linear Regression** is used to predict the student's `exam_score`.

Evaluation metrics:

* MAE
* MSE
* RMSE
* R² Score

### ✅ Pass/Fail Classification

A classification target is created using:

* **Pass:** Exam Score ≥ 50
* **Fail:** Exam Score < 50

The classification model is evaluated using:

* 🎯 Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

## 📋 Model Evaluation

Training and testing performance are compared to identify whether the models show signs of:

* ✅ Good generalization
* ⚠️ Overfitting
* 📉 Underfitting

## 💡 Key Insights

The analysis helps identify the student habits and behavioral factors that have the strongest relationship with academic performance. These findings can be useful for understanding factors that may contribute to better exam outcomes.


## 🚀 Conclusion

This project demonstrates how **data analysis and machine learning** can be applied to student performance data for both **score prediction and Pass/Fail classification**.
